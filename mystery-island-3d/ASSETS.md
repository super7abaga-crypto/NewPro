# Asset Register — Mystery Island 3D

Every external asset that could end up in a distributed build, with its source,
licence and redistribution status. Verified against the publisher's own pages,
not assumed.

## Character pipeline

| Item | Source | Licence | Redistribution | Attribution |
|---|---|---|---|---|
| Base human mesh (19,158 verts / 18,486 tris) | MakeHuman system assets, `makehuman_system_assets_cc0.zip` from files.makehumancommunity.org | **CC0 1.0** | Yes, unrestricted | None required |
| Skin — `young_caucasian_male` + diffuse texture | Same pack | **CC0 1.0** | Yes | None |
| Eyes — `high-poly` mesh, `brown` material | Same pack | **CC0 1.0** | Yes | None |
| Eyebrows — `eyebrow003` | Same pack | **CC0 1.0** | Yes | None |
| Eyelashes — `eyelashes01` | Same pack | **CC0 1.0** | Yes | None |
| Teeth — `teeth_base` | Same pack | **CC0 1.0** | Yes | None |
| Hair — `short02` | Same pack | **CC0 1.0** | Yes | None |
| Clothing — `male_casualsuit02`, `shoes02` | Same pack | **CC0 1.0** | Yes | None |
| Skeleton — 163-bone standard rig | Generated by MPFB2 from the CC0 mesh | **CC0** (output of a GPL tool) | Yes | None |
| Rendered previews in `docs/previews/` | Rendered by us in Blender from the above | **CC0** | Yes | None |

**Licence evidence.** The official pack page
(`https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html`)
lists every asset with an explicit `License: CC0` column, and the archive is
distributed under the filename `makehuman_system_assets_cc0.zip`.

**MPFB2** (`github.com/makehumancommunity/mpfb2`) is **GPL v3** — that covers the
authoring tool only. Exported characters are CC0 output and carry no GPL
obligation into the game.

**Blender** is GPL; used only at authoring time.

## Animation

No animation clips are shipped yet. This is the outstanding character gap.

| Candidate | Licence | Status |
|---|---|---|
| Cinevva animation library (260 motions) | **CC0** | Recommended; retargets onto the MPFB2 humanoid rig |
| CMU Motion Capture Database | Free to use, attribution requested | Fallback; BVH, needs conversion and retargeting |
| Mixamo | **Prohibited for redistribution** — embedded use only | Excluded as a source of committed files |

## Game runtime

| Item | Source | Licence | Notes |
|---|---|---|---|
| Three.js r157 | `vendor/three.min.js` | MIT | Vendored, inlined into `dist/` |
| jsdom | npm, dev-only | MIT | Tests only, never shipped |
| Everything else | Written for this project | — | No other runtime dependency |

The production build makes **zero external requests**: no CDN, no fonts, no
remote textures. Verified by the build's own offline check and by
`tests/offline.test.mjs`.

## Audio

All sound is synthesised at runtime through the Web Audio API. No sampled audio
files are distributed, so no audio licensing obligations apply.
