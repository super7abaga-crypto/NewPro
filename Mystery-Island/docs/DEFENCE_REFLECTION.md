# MYSTERY ISLAND — PERSONAL LEARNING REFLECTION

## The concept I understand now that I didn't before is...

The concept I understand now that I didn't before is how different functions can work together while each has a separate responsibility.

Before this project, I did not fully understand how to organise a Python program into smaller functions or how those functions communicate through arguments and return values.

While building Mystery Island, I learned how `main.py` handles the player's interaction with the game, while `game.py` contains the actual game rules.

I also gained a better understanding of dictionaries, lists, loops, conditions and automated testing.

One important lesson was learning that functions can be stored in dictionaries and called later. Another was understanding how unit tests help identify problems before they affect the user.

The project helped me move beyond simply writing code that works. I now understand more about why code is structured in a particular way, how to test its behaviour, and how to explain the decisions I made.
